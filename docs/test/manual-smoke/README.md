# Manual Smoke Tests

Use this domain for adapter, Plan Mode, initializer, publishing, and README landing smoke checks.

## Domain Map

- [`PLAN_DECISION_WIZARD.md`](PLAN_DECISION_WIZARD.md): sequential decisions, batch confirmation, native input, fallback, and stale-result safety checks before separate execution approval.

- [`PI_ADAPTER.md`](PI_ADAPTER.md): Pi adapter install/load checks, Plan Mode checks, and `/impact-check` checks.
- [`AUTOMATIC_PROJECT_MEMORY.md`](AUTOMATIC_PROJECT_MEMORY.md): fresh ordinary-session automatic Load, active-branch reuse, duplicate suppression, opt-out, and failure-recovery checks.
- [`CROSS_AGENT_ADAPTERS.md`](CROSS_AGENT_ADAPTERS.md): Claude Code, Codex, and cross-agent planning parity checks.
- [`INITIALIZER_AND_PUBLISHING.md`](INITIALIZER_AND_PUBLISHING.md): initializer parity, published Pi install, and README landing review.

Run these checks when changing generated adapter guidance, Plan Mode behavior, initializer resources, packaging, or the README positioning for supported adapters.
