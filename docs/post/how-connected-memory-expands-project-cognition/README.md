# 연결된 메모리는 프로젝트를 이해하는 감각을 확장한다

**Status:** Velog 초안  
**Language:** [English edition](ENGLISH.md)

프로젝트의 목적에 맞게 연결된 메모리는 새로운 지식을 기존 생각과 근거에 통합한다. 현재 알고 있는 범위와 추가로 확인할 항목이 드러나며, 프로젝트에서 중요한 질문과 다음 행동을 감지하는 기준이 세분된다.

이 글에서 인지능력의 확장은 배우고 판단하는 감각이 발전하는 과정이다. 새로운 지식을 기존 지식과 연결하고, 그 관계에서 질문을 발견하고, 목적에 맞는 행동을 선택한다. 행동의 결과는 다시 메모리에 반영되어 이후의 배움과 판단을 발전시킨다.

## 독서 메모가 질문의 해상도를 높였다

`book`은 책을 읽으며 남긴 메모를 개인적인 해석과 후속 연구로 발전시키는 독서 프로젝트다. 이 프로젝트의 초기 메모에는 팩트체크의 역할에 관한 생각이 있었다. 이 메모는 보고서에서 후속 연구 질문으로 연결됐다. 연구가 진행되면서 효과를 사실 인식, 정치적 태도, 공유 행동, 투표 행동과 발화자의 진실에 대한 태도로 구분하게 됐다.

질문의 구분은 조사 범위도 넓혔다. 팩트체크에서 시작한 관심은 프리벙킹과 미디어 리터러시, 언론과 제도, 플랫폼 설계, 숙의와 한국 사회의 적용 맥락으로 이어졌다.

`memo`, `report`, `research`, `record`의 관계는 각 질문의 출발점과 사용한 출처를 보여준다. 관계가 비어 있는 주장은 후속 조사로 이어지고, 조사 결과는 기존 해석을 갱신한다.

하나의 주제를 읽고 요약하던 감각은 결과변수, 근거 수준, 적용 범위와 후속 질문을 함께 살피는 감각으로 발전했다.

## 투자 메모가 판단 기준을 세분했다

`stock`은 시장에 대한 해석, 백테스트, 투자 논지와 실제 거래 기록을 연결해 개인의 투자 판단을 검증하는 프로젝트다. 이 프로젝트에서는 시장 반등에 대한 해석을 백테스트 규칙으로 변환했다. 기본 전략은 19건의 거래와 63.16%의 승률을 기록했다. 평균 거래 수익률과 비용 후 순손익은 음수였고, 목표가 도달 거래의 평균 이익보다 손절 거래의 평균 손실이 컸다.

조건을 엄격하게 적용한 결과는 개선됐지만 전체 표본은 10건, 특정 시장 국면은 1건이었다. 이 조건은 결과를 확인한 뒤 비교한 탐색적 시나리오로 기록됐다. 다른 반도체 종목과 시장의 결과도 함께 비교됐다.

보고서는 결과와 한계를 기록하고, 전략은 적용 조건과 위험 규칙을 갱신했다. 포지션 문서는 종목별 논지와 훼손 조건을 관리했으며, 일지와 거래 데이터는 판단과 실행을 연결했다.

시장에 대한 감각은 가격 방향과 승률에서 기대값, 손실 구조, 표본, 비용, 재현성과 적용 조건으로 확장됐다. 조사 결과는 전략 적용 보류와 추가 검증으로 이어졌다.

## 분쟁 메모가 해결 경로를 구체화했다

`roof-claim-now`는 공동주택 옥상과 누수 공사를 둘러싼 분쟁의 사실과 증거를 정리하고 해결 경로를 찾는 프로젝트다. 이 프로젝트는 확인된 사실, 가설, 미해결 질문, 사실 증거, 법적 근거와 외부 제출물을 식별자로 연결했다. 이 구조를 사용하면서 사건은 공용 부분 사용, 공사 접근, 누수 원인, 구조 하중, 배수와 방수, 행정기관의 확인 권한, 민사적 구제와 당사자 간 운영 규칙으로 나뉘었다.

건축 관련 사실은 행정기관의 확인 질문이 됐고, 소방 규정의 적용은 소방기관이 확인할 범위로 정리됐다. 공사 접근과 방해는 민사적 구제를 검토하는 근거가 됐으며, 향후 작업 절차는 조정안의 운영 규칙으로 발전했다.

증거 문서는 각 자료가 뒷받침하는 사실과 입증 범위를 기록했다. 법률 자료는 적용 조건을 기록했다. 외부 제출물은 확인된 사실과 기관이 조사할 질문을 연결했다.

사건을 이해하는 감각은 경험의 서술에서 사실, 증거, 적용 조건, 판단 기관과 해결 수단을 함께 보는 기준으로 발전했다.

## 연결된 메모리가 프로젝트 감각을 만든다

질문에 연구가 연결되지 않으면 조사 주제가 생기고, 주장에 출처가 연결되지 않으면 원문 확인이 필요하다. 백테스트 표본이 부족하면 검증을 이어가며, 거래 기록이 충돌하면 원장을 대조한다. 사실을 뒷받침하는 증거가 부족하면 자료를 확보하고, 기관의 권한이 불분명하면 관할을 확인한다. 행동 결과는 다시 보고서, 전략, 사실과 출처 기록에 반영된다.

독서 프로젝트에서는 질문의 출발점, 결과변수, 근거 수준과 남아 있는 연구 질문을 함께 살피게 됐다. 투자 프로젝트에서는 시장 해석, 기대값, 손실 구조, 표본, 재현성과 위험 제한을 함께 살피게 됐다. 분쟁 프로젝트에서는 사실, 증거, 적용 조건, 기관의 권한과 해결 수단을 함께 살피게 됐다.

닷닷갓의 메모리 영역은 각 문서가 담당하는 지식의 역할을 정의하고, 트레이서빌리티는 그 지식이 다음 판단과 행동으로 이동하는 경로를 연결한다. 관계가 비어 있는 곳은 현재 지식의 빈칸이 되고, 빈칸을 채우는 과정은 메모리 구조를 다시 정교하게 만든다.

이 순환을 거치며 독서 프로젝트의 질문과 연구 범위가 확장됐고, 투자 프로젝트에서 시장을 판단하는 축이 늘어났으며, 분쟁 프로젝트의 사건은 해결 가능한 질문과 기관별 행동으로 구성됐다. 프로젝트의 목적에 맞게 연결된 메모리는 배움과 행동이 이어지는 지식 지도를 만든다.

[프로젝트의 목적에 맞게 메모리를 설계한다](../designing-project-memory-for-purpose/README.md)에서 프로젝트별 메모리 영역과 관계를 구성한 과정을 살펴볼 수 있다.
